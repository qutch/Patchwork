One spec in, 150 purchase orders out, zero LLM calls

This page replays a real run of the MVP. A hand-written integration spec is compiled into Python with its own tests, a human approves it, and the runner moves every supplier email into Stockroom with no model in the loop. Then Stockroom changes its API, and the runner stops before writing anything wrong.
